### Blog App
A simple and modern blogging platform built with the MERN stack.  
Users can create, edit, and share blog posts with a clean UI.

Authors can:
  - write articles
  - edit articles
  - delete articles
  - view users' comments on their articles

Users can:
   - view articles
   - read articles
   - add comments

Admins can:
  - view active status of all users
  - block user/admin profiles
  - unblock user/admin profiles
---

## Features
- User authentication (login/signup)
- Create, edit, and delete blog posts
- Responsive design for mobile and desktop
- MongoDB backend with Express API
- React frontend with styled components

---

## 🛠️ Tech Stack
- **Frontend:** React , TailwindCss
- **Backend:** Node.js, Express.js
- **Database:** MongoDB 
- **Version Control:** Git & GitHub
