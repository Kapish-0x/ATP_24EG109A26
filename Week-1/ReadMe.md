# Assignments Repository

## Overview
This repository contains solutions to programming assignments.  
Each file demonstrates a specific concept in JavaScript.

## Files Included
- `arrayAsArgument.js` → Demonstrates passing arrays as function arguments
- `emp.js` → Employee data handling example
- `functions.js` → Collection of reusable functions
- `greatestOf2.js` → Program to find the greatest of two numbers
- `greatestOf3.js` → Program to find the greatest of three numbers
- `indexOfArrayElement.js` → Search for an element in an array
- `sumAndMin.js` → Calculate sum and minimum value in an array

## How to Run
Use Node.js to execute any file
node filename.js
