# JavaScript Assignments

## Overview
This repository contains multiple JavaScript assignments demonstrating concepts like arrays, functions, objects, classes, and ES6 features.  
Each file focuses on a specific problem or use case.

## Files Included
- `app.js` → Task management app (add and retrieve tasks)
- `tasks.js` → Task functions with validation
- `books.js` → Book class with borrow/return functionality
- `cart.js` → Shopping cart operations using array methods
- `courses.js` → Array operations on courses
- `deepCopy.js` → Demonstrates deep copy using `structuredClone`
- `details.js` → Object copy using spread operator
- `discount.js` → Coupon validation and discount application
- `ecomApp.js` → E-commerce app integrating products, cart, and payment
- `ecomCart.js` → Cart management functions
- `employees.js` → Employee operations with array methods
- `fruits.js` → Spread operator with arrays
- `marks.js` → Marks analysis (filter, map, reduce, find)
- `movies.js` → Movie dataset operations
- `otp.js` → OTP countdown timer using `setInterval`
- `payment.js` → Payment processing with coupon and stock validation
- `product.js` → Product catalog with stock management
- `setTimeout.js` → Delayed execution using `setTimeout`
- `shallowCopy.js` → Shallow copy example with spread operator
- `students.js` → Student marks and grading system

## How to Run
Use Node.js to execute any file:
node filename.js
