# HTML & CSS Practice

## Overview
This repo contains small practice examples for learning HTML and CSS:
- Nested unordered lists
- Basic page with headings, text, and links
- A styled Larry-the-cat profile page

## Structure
- `unorderedList.html` → Nested snack list
- `1A.html` → Simple page with sections and a link
- `larry-the-cat/`  
  - `index.html` → Hello Kitty profile  
  - `style.css` → Stylesheet

## Usage
Open any `.html` file in a browser.
